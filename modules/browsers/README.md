# Browsers

**Waterfox** - handled by the `browsers` module (close Waterfox first).

**Helium** (or any Chromium browser)
1. Open `chrome://extensions`, turn on **Developer mode**.
2. **Load unpacked** > pick the `helium-crimson-theme` folder. Keep the folder where it is.

**Vivaldi**
Settings > Themes > Editor > **Import**, pick `vivaldi-crimson-theme.zip`.
If there's no import button, make a new theme with:
Background `#1e0a0e`, Foreground `#f2e6e7`, Highlight `#dc143c`, Accent `#dc143c`, Window `#120809`.
