# Steam

Steam dropped skin support a while ago, so this uses [Millennium](https://steambrew.app).

1. Run the `steam` module (or `apply.ps1` here). It closes Steam and opens the Millennium installer.
2. Open Steam, click the Steam logo top left > **Millennium** > **Themes**, install **Simple Dark** and hit **Use**.
3. Go to **Quick CSS** > **Open Editor**, paste everything from `quickcss-crimson.css`, save.

Simple Dark doesn't have a color picker anymore, so the Quick CSS just overrides its grey variables with crimson/black ones.
After a big Steam update Millennium sometimes needs a re-run of its installer.
